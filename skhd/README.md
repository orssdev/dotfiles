# skhd

Global hotkeys via [skhd](https://github.com/koekeishiya/skhd), configured in `.config/skhd/skhdrc`.

## Hotkeys

| Hotkey | Action |
|---|---|
| `ctrl - 2` | Open iTerm |
| `ctrl - 3` | Open Zen |

`ctrl - 1` is left unbound — it's reserved by macOS Mission Control (System Settings → Keyboard → Shortcuts → Mission Control → "Switch to Desktop 1").
